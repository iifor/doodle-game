# 联机房间与 PVP

## 和朋友一起玩

1. 双方打开同一版本游戏，进入“联机对战”，填写昵称。
2. 一人创建私人房间，把游戏网址和五位房间码发给朋友；朋友输入房间码加入。
3. 房主点击“开始对局”，每位玩家再点击“进入战场”，完成浏览器鼠标和音频授权。
4. 按 Tab / 手柄 Create 查看计分板，Esc / Options 打开对战菜单。联机菜单不暂停战场。

公开房间使用 PUB0–PUB15，可在“加入公开房间”中选择编号，也可直接输入房间码。房间满员、编号不存在、信令失败、连接超时均显示错误，不会悄悄新建房间或切换单机。

当前支持自由混战，最多 10 人；先到 20 杀获胜，时限 10 分钟。至少两名玩家进入战场后计时；生命 110，阵亡 2.5 秒后复活，出生保护 2 秒，主动攻击立即结束保护。支持对局中途加入、自动回血、公共弹药补给、枪械、武士刀格挡与手雷。

## 访问方式

默认沿用 PeerJS 公共信令服务，客户端通过 WebRTC 数据通道通信。字体、图形和客户端代码在构建中本地打包；联机需要网络连接。PeerJS 在用户主动连接时才加载。

本机开发：

```sh
npm ci
npm run dev -- --port 5180
```

`127.0.0.1` 只表示当前设备，不能将这个地址发给另一台设备。开发服务默认允许局域网访问：同一网络中的朋友可打开终端 `Network` 行显示的网址，如 `http://<运行电脑的局域网 IP>:5180/`（与上面的端口一致；直接运行 `npm run dev` 时为 5173）。

跨网络时，朋友可在自己的电脑运行同一份项目；也可将 `npm run build` 生成的 `dist/` 部署到 HTTPS 静态站点，让双方访问同一网址。

房间号与原 `doodleshooter` 使用不同的协议命名空间，双方必须使用这个项目的版本，不能和旧版客户端混连。

## 本地信令验证

需要排除公共信令服务影响时，可明确选择仓库提供的本机信令服务。它只监听本机地址，不是公网部署方案。

终端一：

```sh
npm run signal
```

终端二：

```sh
VITE_PEER_HOST=127.0.0.1 VITE_PEER_PORT=9000 VITE_PEER_SECURE=false npm run dev -- --port 5181
```

然后用两个浏览器打开 `http://127.0.0.1:5181/`。这仍然是真实 WebRTC 连接，不是内存消息模拟。

自建信令需设置 `VITE_PEER_HOST`、`VITE_PEER_PORT`、`VITE_PEER_SECURE`，服务路径为 `/peerjs`；配置值在构建时生效。未配置自建地址时明确使用 PeerJS 公共服务，自建连接失败不会自动切回公共服务。

## 模块与裁定边界

- `online/transport.js`：PeerJS 连接、版本握手、房间容量、消息大小和频率限制、超时与销毁。发送者身份来自实际连接。
- `online/protocol.js`：房间码、昵称、消息版本、有限坐标、武器编号、动作和快照校验。
- `online/match.js`：房主维护对局、生命、出生保护、计分、复活和补给；对局与生命序号隔离迟到消息。
- `online/combat.js`：房主执行射线、遮挡、近战与手雷伤害计算。伤害值取游戏规则，不接受客户端上报的任意伤害或比分。
- `online/remote-player.js`：移植远端涂鸦人物、持枪姿势、钩索和插值，释放切换武器及退出时的资源。
- `online/multiplayer.js`：网络状态与现有游戏循环、玩家、HUD 的连接。
- `ui/OnlineMenu.jsx`：中文房间、开局、对战菜单与结算界面，昵称通过 React 或 DOM 文本输出。

房主约每 100 毫秒广播房间快照，玩家约每 50 毫秒提交本地状态。网络时钟独立于绘制帧，打开菜单仍继续对战。

这是浏览器房主制；移动、瞄准和弹药消耗仍由客户端执行，房主自身也不是可信服务器。因此没有声称实现服务端反作弊、延迟补偿或竞技级公平性。需要公开竞技时，应将移动、弹药与命中历史一起迁移到专用权威服务器。

## 当前边界

- 移植范围为自由混战，不含合作打波次、队伍模式和 Mexico 地图。
- 房主离开或失去信令连接会明确关闭房间；没有自动房主迁移，也不自动重连或隐藏断线。
- 为避免浏览器长时间挂起后继续运行失真的对局，房主时钟一次停顿超过 2 秒时明确停止房间。房主应保持页面前台运行。
- 沿用公共信令及 WebRTC 默认连通方式；未配置专用 TURN 中继，严格防火墙或部分 NAT 组合可能无法直连。失败会显示具体原因。
- 公开房间提供编号选择，不包含旧版的自动快速匹配或空房自动创建。

使用方式参考 [PeerJS 官方文档](https://peerjs.com/client/getting-started)。
