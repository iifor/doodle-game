# 涂鸦世界核心设计

首版已实现。单一本地角色、固定职业、PVP 完整继承；朋友间互信。以下数值为原型参数。

## 1. 玩法

AI 开放世界角色养成游戏。

**探索 → 完成任务 → 获得经验、装备和属性点 → 提升角色 → 训练或 PVP → 继续探索。**

| 模式       | 核心作用                                                     |
| ---------- | ------------------------------------------------------------ |
| 开放世界   | 探索、任务、战斗，获取成长奖励，永久保存世界变化             |
| 个人训练场 | 练习职业、测试装备与伤害；试用装备不带出，不反复发放成长奖励 |
| PVP        | 使用培养的角色对战；完整继承等级、装备和属性                 |

## 2. 职业

创建角色前可试用，创建后职业永久固定。所有职业保留跑跳、钩索，能独立完成主要探索内容。

每职业 **2 个主动技能＋1 个被动**，一级开放；普攻和通用动作不计入。3/6 级解锁精良/稀有装备；稀有职业装置提供技能一变体，主菜单调整。

| 职业     | 武器         | 特点与成长侧重     | 主动技能           | 被动                   |
| -------- | ------------ | ------------------ | ------------------ | ---------------------- |
| 刀客     | 武士刀       | 近战、生命、反击   | 突进斩、刀气       | 精准格挡强化下一次斩击 |
| 枪手     | 步枪或狙击枪 | 精确射击、武器输出 | 专注射击、战术闪避 | 精准命中改善下一次装填 |
| 炮手     | 榴弹炮       | 生存、范围爆破     | 蓄力炮击、震荡弹   | 减轻自身爆炸伤害       |
| 战斗法师 | 墨能法杖     | 技能输出、空间控制 | 墨能法阵、闪现     | 技能命中返还少量墨能   |

## 3. 成长与属性

- **等级**：职业基础成长、装备与技能变体解锁；原型先做 1–10 级。
- **属性点**：玩家自行分配，累计获取和投入无上限，不受等级上限影响。
- **装备**：提供属性与玩法差异，保留职业弱点。

| 属性     | 作用                                         |
| -------- | -------------------------------------------- |
| 生命     | 提高生命上限                                 |
| 武器强度 | 提高普通攻击伤害                             |
| 技能强度 | 提高技能伤害；枪手提高专注附加伤害与战术护盾 |
| 防护值   | 换算伤害减免                                 |

```text
最终属性 = 职业基础 + 等级成长 + 属性点投入 + 装备加成
普攻伤害 = 武器基础伤害 × 武器强度 / 100 × (1 - 减伤率)
技能伤害 = 技能基础伤害 × 技能强度 / 100 × (1 - 减伤率)
减伤率 = 防护值 / (生命上限 + 防护值)
等效生命 = 生命上限 + 防护值
```

强度基础值为 100；同类加成相加，不逐次相乘。公式为测试方案。无限成长不扩展到移动速度、控制时长或冷却缩减。

## 4. 属性点获取

- 来源：任务完成、首次地标探索、精英事件完成。
- 新地点和合法的新事件轮次可持续提供机会，不设每日或累计上限。
- **测试参数**：每次有效结算 5% 概率获得 1 点；连续 19 次未获得，第 20 次必得，获得后重置。
- 点数与保底跟随角色保存；同一奖励结算只抽取一次，重连、刷新、换世界不能重抽或重领。
- 玩家在战斗外加点；暂以每点增加 1 点所选属性测试，最终收益待平衡。

## 5. 装备

| 槽位     | 作用                     |
| -------- | ------------------------ |
| 职业武器 | 决定攻击方式，受职业限制 |
| 护具     | 提供生命或防护等收益     |
| 职业装置 | 改变一个技能或职业机制   |

- 品质：普通、精良、稀有；先用固定装备属性。
- 每件以一项主要属性、最多一个特殊效果为原则；强化某项能力需要取舍。
- 任务优先奖励本职业可用装备，重要装备有明确获取途径。
- 暂不做强化、宝石、套装、交易和复杂随机词条。

## 6. 世界与任务

- AI 生成街区、建筑、任务背景和受支持的事件组合。
- 程序控制可达性、完成条件、战斗数值、装备效果和奖励结算。
- 建筑承担补给、线索或事件用途；任务完成后留下持久变化。
- 难度按区域与任务分层；所有职业均可完成主要任务。

首个样板：**探索停电街区 → 找到供电站 → 完成挑战 → 恢复供电 → 获得奖励并开放新建筑。**

## 7. 跨模式与存档

- 角色保存职业、经验、装备、属性点及奖励记录；世界保存地图和事件状态。
- 切换世界、模式或重新登录保留成长；生命、弹药和临时效果按模式初始化。
- PVP 开局固定本局搭配与属性，训练场可预览对应规则。
- PVP 完整继承长期养成差距，加入房间时固定属性与装备。
- 本地角色只面向朋友互信；公开房间也使用同样规则，不提供服务器反作弊。
- 角色保存在当前浏览器、当前站点的 localStorage；清理浏览器数据会删除角色。世界仍由本地服务独立保存。
- 加点与换装只在主菜单开放，暂不洗点。新成长在下次进入模式生效。

## 8. 首版落地

- 初次打开选择职业，可先试用；创建后只有一个角色，职业不可变。
- F / G 或触屏技能一 / 二释放职业技能；枪手在主菜单选择步枪或狙击枪。
- 训练沿用波次战斗，显示伤害，支持临时满级装备试用，不保存试用数据或发放成长。
- 每 100 经验升一级，最高 10 级；地标 / 精英 / 供电任务分别奖励 25 / 60 / 150 经验。
- 首次靠近地标结算探索；清理街区结算精英；前往橙色供电标记按 E 恢复供电，开放该街区第一栋住宅。
- 世界先保存完成状态，角色凭世界、地点、事件轮次领取一次；重访补领，不重复抽取。
- 供电任务奖励职业武器；精英奖励护具或装置。等级 6 起产出稀有品质，重复装备不堆叠。
- 稀有装置：技能一伤害 +20%、冷却 +2 秒；枪手改为专注延长 2 秒、冷却 +2 秒。
- 联机 NPC 默认关闭；房主可开启，随机 8–16 秒刷新一只，上限 4 只，不计入玩家击杀。

后续：依据试玩调整成长与技能数值，再扩展任务类型。首版复用 AI 地图与建筑生成，任务使用固定供电模板。

## 9. 职业平衡与组队

- 步枪单发 20；狙击单发 90、爆头 3 倍；法杖单发 36。各模式共用规则。
- 枪手专注附加伤害按技能强度线性增长：步枪倍率增加 `0.25 × 技能强度 / 100`，狙击增加 `0.05 × 技能强度 / 100`；不与武器强度相乘。专注时长固定，不随加点无限增长。
- 刀客技能后有 0.45 秒收招，期间不能接技能或普攻；普通正面格挡减伤 60%；起手 0.26 秒为精准格挡，可完全抵消并反射射击伤害的 60%；射击格挡间隔 0.19 秒，爆炸无法格挡。
- 法师每秒恢复 4 墨能，每技能消耗 30；法阵命中每 2 秒返还 10。法阵持续 4 秒，每 0.5 秒基础伤害 18，共 8 次，带距离衰减。
- 法阵、震荡弹优先落在准星命中的敌人处；墙体阻挡技能。减速期间地面、空中冲刺和钩索水平速度上限均为冲刺速度的 55%；职业位移仍可用于脱身。
- 属性点仍无限制投入；防护直接增加等效生命，避免生命与防护相乘导致后期战斗无限拉长。角色存档无需重置。
- 房主可选自由混战或红蓝组队；新玩家自动平衡分队，房主在大厅调整队伍，双方各至少一人才能开始。
- 组队不伤害或减速队友；队伍颜色显示在角色上。击杀前 8 秒内造成伤害的其他队友记助攻，助攻不重复增加团队击杀。
- 全队先到 20 杀获胜；超时按团队击杀判胜，分数相同为平局。队员离开不扣除团队已获分数，坠落扣所在队 1 分（最低 0）。
- 配合：法师留人、炮手爆破；刀客逼走位、枪手收割。分散、掩体、绕侧和职业位移提供反制。

### 第二轮平衡调整

- **回血**：PVP 每秒恢复 14 等效生命，训练／探索每秒 11；换算为实际生命恢复时使用同一防护公式。生命与防护等量投入时，承伤与恢复收益一致。
- **刀客**：技能后 0.45 秒内不能衔接另一个技能或普攻；挥刀期间也不能用技能取消收招。仍可移动、格挡，界面显示“收招中”。
- **枪手**：战术闪避附带 `40 × 技能强度 / 100` 的战术护盾，持续 4 秒，先于防护减伤吸收伤害；护盾不叠加，阵亡清空，技能强度不延长持续时间。
- **炮手**：炮弹速度 25，轻微下坠；碰到敌人或墙体立即爆炸，未碰撞时 1.2 秒后爆炸。保留范围衰减、自爆减伤及 0.8 秒蓄力，8–18 米命中可落在震荡弹的 2 秒减速窗口内。爆炸画面跟随房主判定。
- **战斗反馈**：远端护盾显示青色轮廓，炮手蓄力显示渐大的橙色光球，刀客收招显示橙色双竖线并放低持刀手；状态结束或阵亡即隐藏。PVP 自己和队友的范围技能为蓝色，敌方为红色，混战中其他玩家均为敌方。
- **引信一致性**：炮弹和手雷只模拟到引信到期位置；炮弹无碰撞时水平最远约 30 米（平射），房主卡顿不会延长飞行距离。卡顿仍可能推迟爆炸事件送达。
- 上述规则同时用于训练、开放世界与 PVP；保留已有角色存档、无限属性点与完整养成继承。
