# 手机网页

面向 iPhone Safari 与安卓 Chrome，菜单和房间支持竖屏，战斗使用横屏。手机与电脑使用同一玩法与房间协议，不需要安装 App。微信小游戏和独立 App 尚未实现。

## 操作

| 控件            | 操作                                                             |
| --------------- | ---------------------------------------------------------------- |
| 左侧摇杆        | 移动，推远加速至正常移动速度；疾跑按钮单独开关，停止前进解除     |
| 右侧空白 / 射击 | 滑动调整视角；按住射击并拖动可同时瞄准，持刀时挥刀               |
| 瞄准 / 格挡     | 枪械点击切换开镜；武士刀按住格挡                                 |
| 跳跃 / 滑铲     | 保留二段跳、蹬墙跳、地面滑铲、空中冲刺                           |
| 钩索            | 点按摆荡，长按拉近；搭配跳跃弹射，再点按松开                     |
| 手雷            | 按住蓄力、松手投掷；系统取消触摸、暂停或切后台时取消蓄力，不投掷 |
| 拔刀 / 冲刺斩   | 快捷近战与独立冲刺斩按钮，发动条件沿用原玩法                     |
| 武器槽 / 装弹   | 点击底部四槽直接换枪或武士刀，装弹独立按钮                       |
| 菜单 / 计分板   | 点击打开；计分板再次点击关闭，联机时可滚动查看全部玩家           |

支持多指独立操作；高级组合动作建议三指以上。未加入自动射击、自动瞄准和手机专属伤害加成。触摸滑出按钮后仍归原控件处理，避免误触其它动作。

## 设置与限制

- 触屏灵敏度单独保存，鼠标和手柄设置不受影响；反转垂直视角对三种输入均生效。
- 手机首次运行默认“流畅”，渲染像素比上限 1；“标准”上限 1.5。画质只改变渲染分辨率，玩法、敌人数和涂鸦效果不变。旧存档保留，新字段仅在不存在时采用初始值。
- 竖屏不能开战。战斗中转为竖屏，输入清空并显示横屏提示，恢复横屏后点击继续。单人暂停；PVP 对局继续计时，玩家仍可能受到攻击。
- 手机房主切后台后可能被系统挂起。沿用房主模拟停顿超过 2 秒关闭房间的规则，不自动迁移房主或重连。房主需保持页面前台。
- 画布和 HUD 跟随可见区域缩放，按钮避开刘海和安全区；不依赖全屏或屏幕方向锁定权限。
- 图形能力不足、音频启动失败、网络断开等仍会报错，不用自动切换玩法掩盖问题。

## 实现边界

`touch-input.js` 管理触点、持续动作、点击队列与取消；`ui/TouchControls.jsx` 仅提供静态 React 控件，`ui/mobile.css` 管理布局。输入直接由游戏帧采样，不通过 React 每帧更新摇杆或视角。会话负责启停、设备切换、可见区域和音频；沿用现有玩家与联机模块。

## 验收

自动化触摸模拟不能代替真机性能与浏览器兼容性结论，已完成项见 [验证记录](verification.md)。

真机待验收：一台 iPhone Safari、一台安卓 Chrome，记录具体机型、系统和浏览器版本；各完成单人前 5 波，逐项操作四种武器、钩索、手雷及移动技能；与电脑完成建房、加入、击杀、复活和离房，检查旋转、切后台和软键盘。

性能目标为中档手机持续游玩达到 30 FPS。需在真实设备上记录帧率、卡顿和发热情况，未测量前不宣称达标。
