# 发展与试玩运营计划

定位：PC 优先，朋友小队合作探索涂鸦城镇；固定职业、永久养成，训练用于试验，PVP 用于完整继承实力的切磋。

## 阶段与验收

| 阶段         | 交付                                                   | 进入下一阶段的条件                                                            |
| ------------ | ------------------------------------------------------ | ----------------------------------------------------------------------------- |
| 1 · 完整样板 | 第一章“重燃街区”、设施补给、章节结算、角色备份恢复     | 真人无需作者逐步指导，能完成区域、保存退出、再次继续；单人及 2–4 人小队均验收 |
| 2 · 邀请测试 | 首轮建议 10–20 人；修引导、连接、成长节奏和职业问题    | 出现主动再次游玩的玩家；主要卡点与退出原因可解释                              |
| 3 · 长期可玩 | 区域威胁分层、每职业两种装备方向、满级挑战、可组合任务 | 满级后仍有目标，新内容能稳定制作                                              |
| 4 · 扩大开放 | 简化启动、连接保障、存档迁移、生成预算                 | 加入成功率、稳定性、维护负担和生成成本达到项目可承担水平                      |

当前完成阶段 1 的代码与自动检查准备；真人连续游玩、体验时长、完成率与再次游玩意愿仍须实测。后续阶段是待办，不代表已交付。每轮只验证一个主要问题，按验收结果推进，不预设公开上线日期。

## 第一章规则

- 新建持续世界包含四个目标：东侧 `(1,0)`、北侧 `(0,-1)`、东北 `(1,-1)`、核心供电站 `(2,-1)`。
- 前三处可自由决定顺序；建议从东侧开始。遭遇人数依次为 2、3、4、6，核心据点组合重装、盾兵、步兵、突袭者和狙击手。
- 清理据点后在橙色标记按 E 恢复供电；三个外围街区全部通电后才能恢复核心供电站。地图仍可自由探索。
- 通电后标记变绿，站点每人每 10 秒可补充弹药与一枚手雷，第一栋住宅开放；安全复活点仍在清理完成后开放。
- 四处通电即完成章节。HUD 与世界菜单展示成果、下一步与退出入口；只领取已有地标、精英、供电奖励，章节总结不额外重复发成长。
- 章节以已落盘的供电状态为准，保存失败不算完成；离开、重连、重启与队友在远处不影响进度。
- 旧世界维持原布局、敌人和进度，不自动改造成新章节；旧持续世界也可使用通电补给。

## 合作与长期存档

- 街区修复属于共享建设成果。迟到玩家可在重访时领取自己未领过的世界事件奖励；每角色、每世界事件仅一次，不要求参与原战斗。这是当前明确规则。
- 角色备份包含身份、职业、成长、装备、保底和全部领取记录，世界文件单独备份。空白浏览器可恢复；已有角色仅接受同一角色且不回退成长和领取记录的备份。
- 阶段更新默认保留角色和已修复世界；不兼容变更应先提供备份和迁移办法。

## 试玩执行单

1. 固定版本与访问地址，准备已生成的体验区和角色／世界备份；记录测试版本、人员与房主。
2. 每组 2–4 人，从创建／加入开始，观察首任务、区域挑战、章节完成、保存退出与再次进入。单人另测一次；不要在过程中替玩家操作。
3. 结束时只收集三项：哪里卡住、为什么退出、最想再次体验什么。记录原话与对应位置。
4. 七天后统计主动返回人数及原因；以人数、样本规模和观察记录汇报，不把小样本波动当成稳定结论。
5. 修复后复测同一路径，再招募下一批。招募消息、公开发布和收费须另行安排，本计划不自动执行对外动作。

| 记录       | 定义                                             | 决策               |
| ---------- | ------------------------------------------------ | ------------------ |
| 成功进入   | 尝试创建／加入中，实际进入可操作世界的人数及耗时 | 优先修启动或网络   |
| 首任务完成 | 成功进入者中完成首次供电的人数、耗时和卡点       | 修引导与难度       |
| 再次游玩   | 首次试玩后七天内主动再次进入的人数，注明总样本   | 判断重复体验价值   |
| 满级行为   | 达到 10 级后继续做什么、何时退出                 | 决定长期内容       |
| 稳定与成本 | 断线、存档异常、生成等待、失败重试、实际模型费用 | 决定扩大范围与预算 |

先用自愿反馈与本地日志记录，不增加账号、后台埋点或数据看板。费用按真实调用统计，不承诺每玩家固定成本或无限免费生成。

## 内容、传播与商业化

- 人工确定任务规则、奖励与核心设定；AI 丰富布局和局部表现，程序校验并保存复用。
- 开发记录展示修复前后、职业配合、钩索战斗和建筑发现；活动围绕合作挑战、搭配分享、朋友约战。
- 每轮发布简短变更、已知问题和存档兼容说明。活动奖励优先为纪念记录、称号与外观。
- 前期免费测试；重复游玩得到验证后再评估买断或区域扩展。付费不直接提升战斗属性；托管生成需独立核算持续成本。
- 当前房主制与本地角色面向互信小队；公开竞技、交易和持续在线服务不在本轮承诺内。
