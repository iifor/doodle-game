# 场景

每个场景只写空间用途与玩家能直接感到的气氛。不在场景说明里讲「第几篇」。

## 营地

- **空间**：遮雨棚、补给标识、开阔空地、通往各向街区的路口。
- **气氛**：相对安静，纸面天空完整，地面线条干净。
- **用途**：出生、补给、接委托、死后回落点之一。
- **玩家可见说法**：安全营地 / 补给点。

## 普通街区

- **空间**：道路十字、店面、可选屋顶楼梯与天桥；塔楼、厂房、院落形制可穿插。
- **气氛**：线条发涩、墙角有未干墨斑；远处偶有交火声。
- **用途**：随机遭遇、清据点、探索前进。
- **玩家可见说法**：前方街区名（生成名）+「据点未清理 / 已清理」。

## 渗墨街区（事件变体）

- **空间**：同普通街区，地面污渍更密，能见度略差。
- **气氛**：墨色更重，刷新更密或出现墨渍怪。
- **用途**：串联「潮汐」类任务。
- **玩家可见说法**：补给员只说「那边浓度不对，去看看」。

## 仓库 / 地下稿房前哨

- **空间**：可进入厂房或仓库室内，马道、货箱、狭窄通道。
- **气氛**：灯线乱、墙上有涂改痕迹；敌人配置更整。
- **用途**：固定挑战轮、追查样本线索。
- **玩家可见说法**：旧仓库 / 有人在里头设卡。

## 屋顶层

- **空间**：楼梯上屋顶、天桥连栋。
- **气氛**：风声、纸屑、狙击视线通透。
- **用途**：钩影相关委托、高点清场。
- **玩家可见说法**：上屋顶会合 / 桥那边有动静。

## 剧院废墟（后期）

- **空间**：半塌舞台、座椅区、幕后通道（可新做或用院落+室内拼）。
- **气氛**：空旷回声，偶有少女歌声类环境音（若有）。
- **用途**：橡皮擦或终页相关遭遇。
- **玩家可见说法**：废剧院里还有声音。

## 页心（最终区域）

- **空间**：以营地为核向外畸变的一圈街区，道路被重排。
- **气氛**：熟悉布局错位，标题残页悬浮或贴地。
- **用途**：最终抉择任务场地。
- **玩家可见说法**：营地附近的路不像原来那样了。
