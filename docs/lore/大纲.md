# 涂鸦世界 · 故事大纲

这座城是一本仍在书写的活页世界。墨水能成形、能思考，也会失控。

## 阵营

- **折页社**：守城、制图的雇佣团，维持营地与已定稿街区。
- **涂改派**：地下改稿组织，主张以失控的线换取力量。
- **空白**：不站队。认为污损之页应当整本抹去。
- **溢墨**：自涂改派分裂的激进支派，把活墨当作终极兵器。
