# 第六篇 · 终页

溢墨造出**终页**：一具能改写周围街区笔触的活体标题页。它落在哪里，道路与楼影就按它的意志重排，定稿区也会松动。

空白同时启动整本擦除的议程。若终页扩散，空白会提前下手；若空白得手，所有未干与已定稿的页将一并消失。断笔人被推到页心，必须在终局落下前做出选择。

**定稿**——摧毁终页，压住墨变，保留现有城市，让书写以低风险继续。  
**重绘**——与空白交易，擦去污染最重的篇章，世界收缩，却换得相对干净的新起笔。  
**共笔**——把终页封印在营地核心，由守页人长期看管；故事不结束，只是把笔交给愿意留下的人。

无论哪一条路，只要仍有人走向尚未写完的街区，活页就会继续往前生长。
