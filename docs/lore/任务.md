# 任务

## 写法原则

- 游戏内**不出现**「故事」「主线」「篇章」「设定」等字眼。
- 任务面板只有：目标、地点、一两句口吻像现场交代的话。
- 奖励用补给、弹药、解锁下一委托即可；不解释因果。
- 玩家靠地图变化、敌人种类、NPC 只言片语自己拼图。

下表「对内」列仅供设计对照，禁止进游戏文案。

## 任务链

### Q0 · 出门

|          |                                                  |
| -------- | ------------------------------------------------ |
| 对内     | 第二篇开头：学会清街                             |
| 接取     | 自动 / 补给员                                    |
| 目标     | 清理营地相邻一处据点                             |
| 玩家可见 | 「路口那边不安静。清干净再回来补弹药。」         |
| 场景     | 营地 → 邻近街区                                  |
| 完成     | 据点标记已清理；补给员：「还行。东边也一样乱。」 |

### Q1 · 再清两处

|          |                                                                |
| -------- | -------------------------------------------------------------- |
| 对内     | 第二篇：定稿扩散、双派残响同场                                 |
| 接取     | 补给员                                                         |
| 目标     | 再清理两处户外据点                                             |
| 玩家可见 | 「多拿回两条街。看见袖章别愣，先开枪。」                       |
| 场景     | 普通街区                                                       |
| 完成     | 「有人在找一样从仓库丢的东西。你要是路过……」埋下一句，不展开。 |

### Q2 · 旧仓库

|          |                                         |
| -------- | --------------------------------------- |
| 对内     | 第三篇：地下稿房前哨                    |
| 接取     | 补给员（线索）或仓库门口提示            |
| 目标     | 进入仓库，完成一轮清场                  |
| 玩家可见 | 「旧仓库有人设卡。进去把里面清掉。」    |
| 场景     | 仓库                                    |
| 完成     | 「地板下面还有味道。先别追。」；解锁 Q3 |

### Q3 · 大家伙

|          |                                                        |
| -------- | ------------------------------------------------------ |
| 对内     | 第三篇：初号草稿                                       |
| 接取     | 刀口或补给员                                           |
| 目标     | 在指定仓库/街区击败涂鸦巨人（可先逃走一次再决战）      |
| 玩家可见 | 「里头有个不肯倒的。打跑也行，打倒更好。」             |
| 场景     | 仓库或渗墨街区                                         |
| 完成     | 「它跑了。」或「倒了。墙上字别碰。」；茜线可在此后出现 |

### Q4 · 浓度

|          |                                                    |
| -------- | -------------------------------------------------- |
| 对内     | 第四篇：墨团潮                                     |
| 接取     | 补给员                                             |
| 目标     | 在标记为异常的街区存活并清理，或击败墨渍怪         |
| 玩家可见 | 「那边黑得不对。去压一压，别被溅到。」             |
| 场景     | 渗墨街区                                           |
| 完成     | 茜线：「未干的账，总要有人写完。」仅此一句，无解说 |

### Q5 · 上屋顶

|          |                                    |
| -------- | ---------------------------------- |
| 对内     | 第四篇：钩影编制                   |
| 接取     | 信使                               |
| 目标     | 经楼梯/天桥清理屋顶敌人或送达信标  |
| 玩家可见 | 「桥对面有人。走上面，别走街心。」 |
| 场景     | 屋顶层                             |
| 完成     | 「下次还走上面。」                 |

### Q6 · 粉白

|          |                                  |
| -------- | -------------------------------- |
| 对内     | 第五篇：擦除者                   |
| 接取     | 突发事件 / 茜线                  |
| 目标     | 击败或逼退橡皮擦                 |
| 玩家可见 | 「有东西在抹房子。别被它擦到。」 |
| 场景     | 剧院废墟或普通街区突变           |
| 完成     | 「它还会来。营地多留个人。」     |

### Q7 · 路不对了

|          |                                                 |
| -------- | ----------------------------------------------- |
| 对内     | 第六篇：终页将至                                |
| 接取     | 补给员                                          |
| 目标     | 调查营地附近被改写的街区，收集/销毁标题残页线索 |
| 玩家可见 | 「门口那条路昨儿还不是这样。去看看谁在改。」    |
| 场景     | 页心外围                                        |
| 完成     | 引出最终任务；仍不说明三结局名称                |

### Q8 · 收尾（三选一，只给动作）

| 玩家可见选项           | 对内结局 |
| ---------------------- | -------- |
| 「毁掉那张大页」       | 定稿     |
| 「让粉白的把脏的抹掉」 | 重绘     |
| 「拖回营地锁起来」     | 共笔     |

最终界面只确认做了哪件事与世界即时变化（街是否还在、营地是否安稳），不弹设定总结。

## 日常可重复

- **清据点**：无编号，文案轮换短句即可（「又湿了一块」「去定住那边」）。
- **仓库再开一轮**：门旁「再来一次」；不升格剧情。

## 文案禁区

不要写：墨核实验、折页社历史、空白的哲学、篇章名、结局释义、阵营说明书。  
可以写：地点、人数、危险特征、谁让你去、做完拿什么。
