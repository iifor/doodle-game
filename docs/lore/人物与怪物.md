# 人物与怪物

设计侧对照故事；游戏内名称与简介不解释阵营史，只给外观与遭遇印象。

## 友方 / 可遇人物

| 代号     | 游戏内称呼 | 印象                 | 作用                         |
| -------- | ---------- | -------------------- | ---------------------------- |
| 营地留守 | 补给员     | 棚下忙着清点弹药的人 | 发任务、补给、简短指路       |
| 茜线     | 茜线       | 短发、双刃、话少     | 中后期出现，只说具体要做什么 |
| 折锋教官 | 刀口       | 教近战的老佣兵       | 一次近战相关委托             |
| 钩影信使 | 信使       | 常在屋顶出没         | 一次机动/屋顶相关委托        |

玩家本人在游戏内不被赋予称号；他人最多叫「能开枪的那个」。

终页为新首领设计位；未实装前任务可停在「追查巨型标题残页」的线索阶段。

## 命名原则

- 对外：短、好记、像外号或目击者说法。
- 对内：可保留设定名，但不得出现在任务面板、HUD、加载提示。
