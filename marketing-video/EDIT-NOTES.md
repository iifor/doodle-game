# 涂鸦街区 · 抖音推广视频

成片：out/doodle-douyin-v1.mp4
规格：1080 × 1920，30 FPS，32 秒，H.264 / AAC。

## 预览与导出

在本目录运行：

```powershell
npm.cmd run dev
npx.cmd remotion render DoodlePromo out/doodle-douyin-v1.mp4 --concurrency=4 --crf=18
```
